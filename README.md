# Portfolio — N'Dri Moahe O.

Portfolio fullstack réalisé avec React, TypeScript et Vite. Il présente une sélection de projets et un catalogue consultable de **120 dossiers** trouvés dans `all project`.

## Lancer le projet

```bash
npm install
npm run dev
```

Pour produire la version statique : `npm run build`.

## Mettre à jour les projets

Les cartes et le catalogue sont dans `src/projectData.ts`. Les liens GitHub affichés sont ceux repérés dans les remotes Git locaux appartenant au compte `nikola-moon`. Un projet sans lien confirmé porte la mention « Projet local ».
